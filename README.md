# Personal Profile Website

A simple multi-page personal profile website created while learning **HTML and CSS**. The website presents my introduction, academic background, projects, and responsibilities through separate web pages.

##  Project Overview

This project was created to practice the fundamentals of web development and understand how multiple HTML pages can be connected through navigation links and styled using CSS.

## Features

* Personal introduction section
* Academic/Education page
* Projects page
* Responsibilities page
* Navigation between multiple HTML pages
* Basic CSS styling
* Responsive and simple page layout

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code

## Project Structure

```text
personal-profile-website/
│
├── index.html
├── style.css
├── Education.html
├── project.html
├── Responsibilities.html
└── README.md
```
